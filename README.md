# Chinese reading

Resources for learning Chinese, with a focus on reading and vocabulary practice. [Browse the articles](articles/).

## Read offline

Open the folder for the article you want to read. Select its HTML file, choose **Download raw file** on GitHub, and open the saved file in Chrome.

For pinyin and English definitions, install [Zhongwen: Chinese-English Dictionary](https://chromewebstore.google.com/detail/zhongwen-chinese-english/kkmlkkjojmombglmlpbpapmhcaljjkde). In `chrome://extensions`, open Zhongwen’s **Details** and turn on **Allow access to file URLs**. Reload the article, turn on Zhongwen, and hover over a Chinese word.

## Add an article

Give each article its own folder under [articles/](articles/), named for its topic. Place the HTML file inside and embed any images in the HTML so they work offline. To add it on GitHub, open `articles/`, choose **Add file → Upload files**, drag in the whole article folder, and select **Commit changes**.
